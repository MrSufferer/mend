# Project and dependency licenses

Mend project code is distributed under the [MIT License](../LICENSE), selected by the project owner for this release. Third-party code retains its own licenses and attribution requirements.

The generated [lockfile inventory](release-license-inventory.json) records all255 dependency entries, including development and optional platform packages, with version, declared license, integrity, installed status and collected notice hashes. It is bound to the exact SHA-256 of `package-lock.json`. This is a dependency inventory, not a claim that every optional/development package ships in the production artifact. Regenerate and review it when the lockfile changes; audit actual frontend/backend production outputs before asserting shipped-license completeness.

[Collected third-party notices](release-notices.md) preserve64 unique top-level license/notice texts from installed packages, deduplicated by SHA-256 with package-path attribution, plus the pinned OpenZeppelin and forge-std license texts from the independently initialized contract checkout. OpenZeppelin5.4.0 is MIT; forge-std1.9.7 offers MIT/Apache-2.0 texts. Their exact gitlinks are recorded in [release reproduction](release.md#contract-reproduction).

The lockfile includes MIT, Apache-2.0, ISC,0BSD, BSD-3-Clause, CC-BY-4.0, `(AFL-2.1 OR BSD-3-Clause)`, `(MIT AND Zlib)`, LGPL-3.0-or-later and compound Apache/LGPL/MIT declarations. Native sharp/libvips packages require particular attention when they are shipped. It would be inaccurate to describe all dependencies as MIT/Apache or to assume every optional platform artifact is deployed.

The inventory retains the factual `installedWithoutTopLevelNotice` list and now includes supplemental official upstream texts and source hashes. Exact version-tag/commit texts were fetched for AI provider-utils, native esbuild variants, sharp-libvips (including its full bundled third-party notices), canvas, Next.js, x402 and Drizzle ORM/Kit. The AWS SDK3.1150.0 tag was checked to contain the exact installed internal credential-provider-http3.972.76, credential-provider-login3.972.81 and nested-clients3.997.48 versions; its Apache text is included. The upstream brocli0.10.1 license is explicitly a nearby-version reference because no0.10.2 tag was available; brocli is development tooling and has no external reference in the observed frontend output. React's official MIT text supplements client-only's MIT declaration without asserting a separately pinned client-only release source. These distinctions remain in the notice provenance.

The local production build has29 Next trace files. External traced dependencies include the three AWS internal packages, Next env, client-only and the native sharp/libvips binary; the collected supplemental texts cover their declared licenses, and libvips upstream full third-party notices are included. `localFrontendTraceObservation` maps observed external files to installed packages. Some imports are bundled inline; absence from an external trace does not establish exclusion from frontend or backend bundles. Different provider platforms can select different native optional packages. Record the final provider source/build identity and audit its actual shipped artifacts; this local observation is not a universal legal compliance conclusion. Retain these notices with distributed artifacts and obtain corresponding native source/relinking material where its license requires it. No known traced missing top-level license text is silently omitted.

## Shipped fonts

The root layout imports `Geist` and `Geist_Mono` through Next16.4.0. The resulting local production CSS self-hosts WOFF2 files, whose exact names, lengths and SHA-256 hashes are recorded under `fontAssets` in the inventory. Geist and Geist Mono are **SIL Open Font License1.1 (OFL-1.1)**, copyright2024 The Geist Project Authors. Both complete OFL texts and upstream copyright lines are included in [font notices](release-notices.md#geist-and-geist-mono-font-notices). Their authoritative Google Fonts license-file commits are recorded separately for each family; these pin the fetched notice text and do not pretend to identify the source revision of Google's downloaded font binaries. Preserve font copyright/license text when copying/distributing these assets, and recheck the final provider artifact if the font download or platform changes.
