## Lifecycle and source findings

The reviewer traced session creation/revocation and wallet generation fences; owner-gated upload/result routes; byte/hash/expiry verification before and after object retrieval; payment authorization, settlement attempt persistence and canonical receipt checks; conversion publication/whole-stop evidence; agent call admission and tool authority; registrar eligibility and durable signed-operation replay; aggregate debt/capacity; operator actions/health and SQL locking/retention functions. Relevant entry points are [auth](../lib/server/auth.ts), [wallet](../lib/client/wallet.tsx), [orders](../lib/server/orders.ts), [payments](../lib/server/payments.ts), [storage](../lib/server/storage.ts), [health](../lib/server/health.ts), [agent](../backend/agent.ts), [registrar](../backend/registrar.ts), [desk](../app/live.tsx) and [migrations](../drizzle).

The lifecycle suite exercises loss of settlement response without another charge; orphan receipt rejection; hard-killed parser and post-PUT publication uncertainty; cooperative whole-stop and restoration without extending clocks; twelve persisted SDK dispatch claims across worker death, the actual60-second expiry and deterministic repayment after exhaustion; registrar signed-byte/nonce replay; unbroadcast and submitted-unmined debt; lost refund receipt and canonical pay-once replay; concurrent operator/model single retry; retention deletion interrupted after storage effect; aggregate deficit/refill; late-output/entitlement races; fresh UTC allowance; purchased terms during pause; failed-health retrieval and stale resume invalidation; real signed browser session expiry, wallet changes and in-flight private download fencing; independently scoped web aliases and current operator investigation admission.

Financial outbox fixtures explicitly seed synthetic canonical payment/stopped metadata. The payment crash cases use real submission/settlement HTTP routes against controlled effects. These tests establish application durability and concurrency; they do not establish live-provider cancellation, canonical Arc settlement or current free model access. An elapsed deadline/lease, deleted object, lost response or transaction hash never becomes proof of stopped work, absent output or returned funds by itself.

No reviewed path gives the model raw document bytes, session/signing secrets, private object paths or a free-form endpoint/tool. Case calls are durably claimed before dispatch; tools are server-bound to the current order/invocation and current evidence. Registrar verification is independent from model choice and does not accept an arbitrary payer/amount. Refund disposition fences stale publication and preserves the original payer. SQL security-definer interfaces revoke public execution and runtime roles have narrow grants. This source review is not a formal proof or a claim against compromised infrastructure administrators.
